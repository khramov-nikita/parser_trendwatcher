# Схема базы: Trendwatcher (черновик)

Три таблицы под MVP: источники, события, сводки.  
Наблюдаем за площадками и публичными лентами, не за людьми: полей с ФИО и контактами нет.

У каждого поля — одна строка: что лежит и кто заполняет (**база** / **сборщик** / **нейросеть**).

---

## 1. `sources` — источники

Реестр адресов для опроса. Добавлять и отключать можно без правки кода.

| Поле | Что лежит и кто заполняет |
|---|---|
| `id` | Внутренний номер строки источника. **База** (при вставке). |
| `label` | Служебная метка источника (например «YT RSS seed»). **Сборщик** при заведении источника. |
| `url` | Адрес ленты или endpoint. **Сборщик** при заведении источника. |
| `kind` | Способ сбора: `rss`, `api` или `sitemap`. **Сборщик** при заведении источника. |
| `enabled` | Включён ли источник в опрос. **Сборщик** (по умолчанию `true` ставит **база**). |
| `last_fetched_at` | Время последнего обращения к адресу; пока не опрашивали — пусто. **Сборщик** после каждого запроса. |
| `last_success_at` | Время последнего успешного ответа; пока успехов не было — пусто. **Сборщик** после успешного ответа. |
| `consecutive_errors` | Сколько ошибок подряд; после успеха — `0`. **Сборщик** (старт `0` ставит **база**). |

**Ограничения:** `enabled` и `consecutive_errors` — `NOT NULL`; счётчик ошибок ≥ 0.

---

## 2. `events` — события

Одна строка = один материал, который сборщик уже видел.

| Поле | Что лежит и кто заполняет |
|---|---|
| `url` | Ссылка на материал; уникальный ключ события. **Сборщик**. |
| `source_id` | Ссылка на строку в `sources` — откуда пришла запись. **Сборщик**. |
| `title` | Заголовок или подпись материала (не имя человека). **Сборщик**, если источник отдал. |
| `published_at` | Дата публикации у площадки; если источник не отдал — пусто (`NULL`). **Сборщик**. |
| `collected_at` | Дата обнаружения: когда строка попала в базу. **База** (`DEFAULT now()`, `NOT NULL`). |
| `metrics` | Метрики материала (просмотры, лайки и т.п.) в JSON, если API отдал; иначе пусто. **Сборщик**. |

**Ограничения (PostgreSQL):**

- `url` — `PRIMARY KEY` / уникальность: повтор той же ссылки отклоняет **база**, не код сборщика.
- `source_id` — `NOT NULL`, внешний ключ на `sources.id`.
- `collected_at` — `NOT NULL`, при вставке без поля ставит **база**.
- `published_at` — без `NOT NULL`.

---

## 3. `summaries` — сводки

Недельный топ с пояснением для Telegram (воскресенье 00:00).

| Поле | Что лежит и кто заполняет |
|---|---|
| `id` | Внутренний номер сводки. **База** (при вставке). |
| `period_start` | Начало периода сводки. **Нейросеть** при сборке. |
| `period_end` | Конец периода сводки. **Нейросеть** при сборке. |
| `body` | Текст топа с пояснениями (платформа, почему в топе, ссылки). **Нейросеть**. |
| `sent_at` | Когда отправили в Telegram; до отправки — пусто. **Сборщик** после отправки. |

---

## Что сознательно не храним

- ФИО, ники, email, телефоны, Telegram-id и любые контакты людей.
- Секреты (API-ключи, токены).
- Сырые HTML/ответы API целиком.
