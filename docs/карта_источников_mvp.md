# MVP трендвотчера

Сужение паспорта до того, что закрывается **белым контуром** (RSS / официальный API / sitemap + проверенные агрегаторы). Без HTML-сбора, captcha и обхода авторизации.

Связанные доки: [`паспорт_продукта.md`](паспорт_продукта.md), [`паспорт_продукта_mvp.md`](паспорт_продукта_mvp.md), [`карта_источников.md`](карта_источников.md).

## Цель MVP

Еженедельная сводка в Telegram (воскресенье 00:00): топ с пояснением по сигналам, которые робот реально видит — в первую очередь **Shorts**, плюс догон по **известным** хэштегам на Reels и (если будет доступ) TikTok Research.

## Что в авто (ядро MVP)

| № | Событие | Платформа | Источник | Как работает |
|---|---|---|---|---|
| 7 | Взрывной ролик по метрикам | Shorts | YouTube Data API | Ежедневный опрос статистики по watchlist / search |
| 9 | Появление у отслеживаемых источников | Shorts | RSS `feeds/videos.xml?channel_id=` + Data API | Seed-каналы (список задаёшь ты) |
| 16 | Высокая вовлечённость | Shorts | YouTube Data API | Comments/likes относительно views между снимками |
| 17 | Устойчивый рост 3+ дня | Shorts | YouTube Data API | Серия ежедневных замеров, не разовый скачок |

**Минимум для старта:** API-ключ YouTube + список seed `channel_id` (ориентир 10–30 каналов EN/RU/ZH по нише).

## Что в авто условно (если доступы есть)

| № | Событие | Условие | Источник |
|---|---|---|---|
| 8 | Кластер копий | Есть whitelist хэштегов/запросов | IG Graph `recent_media` / `top_media`; YT search по одному сигналу |
| 10 | Текстовый шаблон | Те же whitelist / caption·title | Graph / Data API |
| 7, 9, 16, 17 | То же ядро | Approved TikTok Research | Research API |

Без Instagram Business/OAuth и без Research — эти строки **не обещать** в сводке.

## Полуручной seed (discovery вне авто)

Официального белого топа хэштегов/звуков нет. Раз в неделю (до сборки сводки) вручную заносишь кандидатов из UI платформ (Charts / Reels Trends / Creative Center). Робот дальше только **отслеживает** их белым API.

| № | Событие | Роль в MVP |
|---|---|---|
| 1–2 | Хэштег в трендах / резкий рост | Seed-список → опрос Graph/API |
| 4–5 | Звук в трендах / рост использований | Seed (для Shorts — из Charts UI) → трекинг, если API отдаёт метаданные |
| 6 | Вариации трека | Только если видно в метаданных seed-звука |
| 13 | Официальный тренд-лист | Фиксируешь факт «взял из UI» вручную в карточке seed |

Событие **3** (кросс-хэштег) в MVP: только если один и тот же seed отмечен на 2+ платформах.

## Вне MVP (отложить)

| № | Событие | Почему |
|---|---|---|
| 3* | Кросс-платформа как системный поток | Нет стабильных топов на TikTok/Reels |
| 11–12 | Тема / сезонный всплеск как ядро | Только опционально через Google Trends позже |
| 14–15 | Расхождение и скорость миграции | Нужна история first_seen на 2+ платформах |
| 1–6, 13 | Как полностью автоматический discovery | Нет белого API топов |

\* точечный кросс по ручному seed — допустим; системный поток — нет.

## Фильтры MVP (из паспорта, без новых порогов)

Включены по смыслу, числа — **не задано** (как в паспорте):

- отсев разового всплеска, слабого роста, малого объёма, низких метрик, низкой вовлечённости  
- дедуп за окно N дней, шум/неполный сигнал, возраст записи  
- языки: EN / RU / ZH  
- только TikTok / Reels / Shorts (на MVP факт выдача в основном Shorts)  
- нет хэштега/звука/шаблона → в топ не класть, если нечего операционализировать  

Пороги задать после первой тестовой недели.

## Формат недельной сводки MVP

Топ с пояснением. В каждом пункте минимум:

- платформа  
- тип сигнала (ролик / хэштег-seed / звук-seed)  
- почему в топе (метрика или «рост N дней» / «новый у seed-канала»)  
- ссылка или ID  
- язык/рынок, если известен  

Читаемость 5–10 минут; сверху — сильные по метрикам Shorts.

## Критерий «MVP полезен» (из паспорта, упрощённо)

1. Из топа берёшь в работу ≥ N пунктов (N задашь после теста).  
2. По пункту ясно, что снимать или что проверить.  
3. Сводка заменяет ручной обход хотя бы YouTube Shorts.  
4. Мало пустых недель по ядру 7/9/16/17.

## Порядок внедрения

1. YouTube Data API + seed RSS-каналы → события **7, 9, 16, 17**.  
2. Whitelist хэштегов + Instagram Graph (если доступ есть) → **8, 10**.  
3. TikTok Research (если одобрят) → то же ядро на TikTok.  
4. Еженедельный ручной seed звуков/тегов → полуавто **1–6, 13**.  
5. Когда появятся данные на 2+ платформах — вернуть **14–15** в бэклог автоматики.

## Явно не делаем в MVP

- парсинг Creative Center / Reels Trends / Charts UI  
- corp newsroom/careers как источник трендов  
- обещание полного топа TikTok+Reels+Shorts без белых топ-API
