# Паспорт продукта: Trendwatcher (короткие видео)

MVP-срез: [`паспорт_продукта_mvp.md`](паспорт_продукта_mvp.md).

## 1. Продукт

Робот-трендвотчер: следит за публичной активностью в коротких видео и присылает сводку по новым и быстрорастущим трендам.

## 2. Ниша и платформы

- **Ниша:** мониторинг трендов в коротких видео
- **Платформы:** TikTok, Reels, Shorts
- **Рынки/языки:** англоязычный, русскоязычный, китайский
- **Цель:** автоматически отслеживать и структурировать новые/быстрорастущие тренды → топ хэштегов, звуков и вирусных паттернов

## 3. Источники данных (приоритет)

1. RSS
2. API
3. sitemap.xml
4. HTML-вёрстка — только если нет первых трёх

## 4. Что считается событием

1. Хэштег в официальных/публичных трендах
2. Резкий рост хэштега
3. Кросс-платформенный хэштег
4. Новый/быстрорастущий звук в публичных трендах
5. Рост использований звука во времени
6. Вариации трека (sped-up / slowed / remix) по метаданным
7. Взрывной ролик по метрикам
8. Кластер копий вокруг одного сигнала
9. Появление ролика/темы у отслеживаемых источников
10. Новый текстовый шаблон
11. Новая тема/нарратив на уровне текста
12. Сезонный/новостной всплеск
13. Попадание в официальный тренд-лист
14. Расхождение платформ
15. Скорость миграции между платформами
16. Высокая вовлечённость (если метрики доступны)
17. Устойчивый рост 3+ дня

## 5. Что отсекается

1. Разовый всплеск
2. Слишком слабый рост
3. Малый объём
4. Низкие абсолютные метрики
5. Низкая вовлечённость
6. Дубли за окно N дней
7. Шум парсинга
8. Устаревшие записи
9. Неполный сигнал
10. Чужой язык/рынок (вне EN / RU / ZH)
11. Только одна платформа
12. Вне TikTok / Reels / Shorts
13. Нет хэштега / звука / текстового шаблона
14. Слишком широкая тема из стоп-листа
15. Явный promo/ads (если видно в данных)

**Пороги отсечения:** не задано

## 6. Доставка сводки

| Параметр | Значение |
|---|---|
| Кому | Только владельцу |
| Куда | Telegram |
| Сбор | Каждый день |
| Отправка | Раз в неделю: **воскресенье, 00:00** |
| Формат | **Топ с пояснением** (почему пункт в топе) |

## 7. Когда сводка считается полезной

1. Из топа взято в работу ≥ N пунктов
2. По пункту ясно, что снимать (звук / хэштег / шаблон)
3. Из сводки собирается недельный контент-план без доп. поиска
4. Доля мусора/дублей ниже порога
5. Почти нет «пустых» недель (минимум M идей)
6. Пункты свежие в заданном окне
7. Заменяет ручной обход трёх платформ
8. Читается за 5–10 минут
9. Есть приоритизация (сверху важное)
10. В пункте достаточно полей: платформа, сигнал, метрика/причина, ссылка или ID

**N, M, порог мусора, окно свежести:** не задано

## 8. Вне скоупа (сейчас не делаем)

Разбор кадра/видео, детекция накрутки, точная стадия «выгорания», атрибуция роста роликов к сводке.
